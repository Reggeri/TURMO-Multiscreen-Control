# Képillesztés és telefonos képátküldés

**Theme Editor:** IMAGE / MP4 → válassz képet. IMAGE FIT: cover (kitölti, vág), contain (teljes kép, kerettel), stretch (nyújtás). ZOOM: nagyítás. Jelöld be MOVE BACKGROUND, majd húzd a képet az előnézeten a vágás beállításához. CENTER középre igazít. SAVE THEME ment.

**Telefon:** Phone Remote → Enable remote + QR → QR beolvasás és PIN. Display 1/2 alatt válassz JPEG/PNG képet (legfeljebb 8 MB), majd Send photo. A program Custom témára vált és megjeleníti a képet. A kijelző újraindulhat a témaváltáskor.

A képek csak a számítógépen, a felhasználói TURMO-Control/phone_images mappában tárolódnak. A szolgáltatást kizárólag megbízható otthoni hálózaton engedélyezd.
