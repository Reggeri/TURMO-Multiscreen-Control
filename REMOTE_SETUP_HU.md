# TURMO telefonos vezérlés (v0.28.15)

1. Indítsd el a TURMO Controlt Windows alatt.
2. Settings -> PHONE REMOTE / QR -> Enable remote + QR.
3. A telefon legyen ugyanazon a helyi hálózaton. Olvasd be a QR-kódot.
4. Írd be a PC-n látható hatjegyű PIN-t.
5. Válts témát, állíts fényerőt, indítsd/leállítsd a kijelzőket.

A téma megváltoztatásakor a kijelzők újraindulnak, mert a renderelők induláskor választódnak ki.
A QR csak a helyi címet tartalmazza, a PIN-t nem.
A kiszolgáló csak akkor indul el, ha engedélyezed, és a Disable remote gombbal leállítható.
Ha a telefon nem éri el, engedélyezd a Windows tűzfalon a helyi/privát hálózati hozzáférést, ne nyiss portot az internet felé.
A helyi HTTP kapcsolat nincs titkosítva: csak megbízható otthoni Wi-Fi-n használd.
